# 📷 แปลเมนู

ถ่ายรูปเมนูหรือป้ายภาษาต่างประเทศ แปลเป็นภาษาไทยด้วย AI (Gemini) ใช้คู่กับ [TripBudget](https://focus2541.github.io/tripbudget/)

🔗 **เปิดใช้งาน:** https://focus2541.github.io/Menu/

## ทำอะไรได้
- 🍜 **แปลเมนู**: ชื่อไทย คำอ่านภาษาไทย คำอธิบายสั้นๆ ราคา + แปลงเป็นบาท
- 🐷 **บอกส่วนผสม**: หมู (รวมน้ำซุปกระดูกหมู น้ำมันหมู) เนื้อวัว ไก่ อาหารทะเล แอลกอฮอล์ ระดับเผ็ด มังสวิรัติ และของที่มักแพ้
- 🚫 **ตั้งว่าไม่กินอะไร**: ไม่กินหมู ไม่กินเนื้อวัว มังสวิรัติ แพ้อาหารทะเล แพ้ถั่ว ไม่กินเผ็ด → แอปไฮไลต์เมนูที่ควรระวัง และกรองเฉพาะที่กินได้
- 🙋 **สั่งอาหาร**: กด "+ สั่ง" แล้วเปิดหน้าตัวใหญ่ยื่นให้พนักงาน มีชื่อเมนูภาษาเดิม จำนวน และประโยค "ไม่กินหมู / ไม่เอาเผ็ด" ภาษาญี่ปุ่น เกาหลี จีน เวียดนาม อังกฤษ
- 🔊 ฟังเสียงอ่านชื่อเมนู, 👉 ชี้ทีละเมนู
- 🪧 **แปลป้าย/ข้อความ**: ป้ายสถานี ตู้ขายตั๋ว ฉลากสินค้า
- ➕ เมนูหลายหน้า ถ่ายต่อกันได้
- 💰 **บันทึกเข้า TripBudget**: ส่งยอดที่จ่ายจริงเข้าทริปที่เปิดอยู่ (เลือกจ่ายเงินสด/บัตร/บัตรเดินทาง)
- เก็บผลแปล 12 ครั้งล่าสุดไว้ดูย้อนหลัง (ไม่เก็บรูป) ติดตั้งเป็นแอปได้

AI อาจแปลหรือเดาส่วนผสมผิดได้ ถ้าแพ้อาหารรุนแรง ให้ยื่นประโยคแพ้อาหารให้พนักงานยืนยันทุกครั้ง

## ตั้งค่า AI (ทำครั้งเดียว ~5 นาที)
API key อยู่ใน Google Apps Script เท่านั้น ไม่อยู่ในแอปหรือใน GitHub

1. ขอ API key ฟรีที่ https://aistudio.google.com/apikey (ใช้ key เดียวกับแอปกินพอดีได้)
2. เปิด https://script.google.com → New project → ลบโค้ดเดิม แล้ววางโค้ดจาก `apps-script/Code.gs`
3. Project Settings (ไอคอนเฟือง) → Script properties → เพิ่ม
   - `GEMINI_API_KEY` = key จากข้อ 1
   - `APP_TOKEN` = รหัสลับที่ตั้งเอง เช่น ตัวอักษรสุ่ม 16 ตัว
   - `MODEL` (ไม่ใส่ก็ได้) ค่าเริ่มต้น `gemini-flash-lite-latest` (เร็ว) ใส่ `gemini-flash-latest` ถ้าอยากได้คำแปลละเอียดกว่าแต่อาจช้ามาก
   - `PER_HOUR` (ไม่ใส่ก็ได้) จำกัดรูปต่อชั่วโมง ค่าเริ่มต้น 40
4. เลือกฟังก์ชัน `testSetup` แล้วกด Run → อนุญาตสิทธิ์ → ดู Execution log ว่าขึ้น ✅
5. Deploy → New deployment → ประเภท Web app
   - Execute as: **Me**
   - Who has access: **Anyone**
6. คัดลอกลิงก์ที่ลงท้ายด้วย `/exec`
7. ใส่ลิงก์ใน `AI_URL` ของ `version.js` (ใส่ไว้แล้ว) ผู้ใช้กรอกแค่รหัสลับที่หน้าแรกของแอป · ห้ามใส่รหัสลับในไฟล์ของ repo เพราะเป็นสาธารณะ

**ให้เพื่อนใช้**: ในตั้งค่ากด "🔗 ส่งลิงก์ตั้งค่าให้เพื่อน" ส่งทาง LINE เพื่อนกดลิงก์แล้วกด "ใช้เลย" ไม่ต้องตั้งเอง (เพื่อนจะใช้โควตา Gemini ของคุณ ถ้าไม่อยากให้ใช้ต่อ เปลี่ยน `APP_TOKEN`)

ถ้าแก้โค้ด Apps Script ภายหลัง: Deploy → Manage deployments → แก้ไข → Version: New version (ลิงก์เดิมใช้ต่อได้)

## อัปเดตโค้ด Apps Script (เมื่อแอปบอกว่าโค้ดเก่า)
1. เปิดโปรเจกต์ใน script.google.com → ลบโค้ดเดิม → วางโค้ดใหม่จาก `apps-script/Code.gs` → กด 💾
2. Deploy → Manage deployments → ✏️ (แก้ไข) → Version: **New version** → Deploy (ลิงก์ /exec เดิมใช้ต่อได้)
3. (ไม่บังคับ) เลือก `testSetup` → Run ดูว่าโมเดลตอบภายในกี่วินาที

โค้ดเวอร์ชัน 2 เร็วกว่าเดิมมาก: ให้ AI ตอบสั้นลง ปิดการ "คิด" ของโมเดล ป้ายใช้โมเดล lite และไม่ลองซ้ำเมื่อรอนานแล้ว

## ให้ใช้เฉพาะคนที่อนุญาต (โค้ด Apps Script เวอร์ชัน 6 ใช้ร่วมกับ TripBudget ไม่ต้องใช้รหัสลับ มีรหัสยืนยัน 4 หลัก)
ลิงก์ตั้งค่าส่งต่อได้ แต่เครื่องใหม่ทุกเครื่องต้องให้เจ้าของอนุมัติก่อนถึงจะแปลได้
1. สร้างสคริปต์จากใน Google Sheet (ส่วนขยาย → Apps Script) หรือใส่ `SHEET_ID` ใน Script properties
2. เพิ่ม Script property `ADMIN_TOKEN` = รหัสผู้ดูแล (ของเจ้าของคนเดียว ห้ามส่งให้ใคร)
3. วางโค้ด → Run `testSetup` → อนุญาตสิทธิ์ (Google Sheet + ส่งอีเมล) → Deploy เวอร์ชันใหม่
4. ในแอปเครื่องตัวเอง: ⚙️ → ใส่ "รหัสผู้ดูแล" → บันทึกและทดสอบ (สถานะจะเป็น 👑 เจ้าของแอป ใช้ได้ทันที)
5. เพื่อนกดลิงก์ตั้งค่า → ใส่ชื่อ → "ขอใช้งาน" → เจ้าของได้อีเมลมีปุ่ม ✅ อนุมัติ / ⛔ ไม่อนุมัติ
6. จัดการทั้งหมดได้ที่ชีต "เครื่องที่ใช้งาน": เปลี่ยนสถานะเป็น อนุมัติ / ไม่อนุมัติ / ปิด, ดูจำนวนครั้งที่ใช้, ตั้ง "จำกัดต่อวัน" รายคน (ค่าเริ่มต้น `PER_DAY` = 30)

ถ้าเพื่อนล้างข้อมูล Chrome หรือเปลี่ยนเครื่อง ต้องขอใช้งานใหม่

## เชื่อมกับ TripBudget
ใช้ localStorage ร่วมกันบน `focus2541.github.io` (ไม่ผ่านอินเทอร์เน็ต)
- อ่าน `tb_active` (ทริปที่เปิดอยู่: ประเทศ สกุลเงิน เรต) เพื่อเลือกประเทศและแปลงราคาเป็นบาท
- เขียนรายจ่ายต่อท้าย `tb_inbox` เมื่อกด "บันทึก" TripBudget จะดึงเข้าเมื่อเปิดแอป
- รูปแบบข้อมูลดูได้ใน README ของ TripBudget

## ไฟล์
```
index.html      ตัวแอป
version.js      เลขเวอร์ชัน (เปลี่ยนทุกครั้งที่แก้ไฟล์ แอปจะขึ้นแถบ "มีเวอร์ชันใหม่")
sw.js           ใช้งานออฟไลน์ (เปิดแอปได้ แต่การแปลต้องใช้เน็ต)
manifest.json   ติดตั้งเป็นแอป
apps-script/    โค้ด Google Apps Script ตัวกลางเรียก Gemini
```
